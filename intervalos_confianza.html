Se verifica normalidad con Shapiro-Wilk (α = 0,05). Si la variable no es normal, no se calcula el intervalo.

p = número de éxitos / número de filas con valor.

Se verifica igualdad de varianzas (prueba F) y normalidad en ambas muestras. Si las varianzas difieren se usa la alternativa de Welch.

Cada fila es un par. Se usan las filas con ambos valores numéricos y la diferencia es Medición 1 menos Medición 2. Se verifica normalidad de las diferencias.

p de cada grupo = éxitos / filas con resultado. La diferencia es Grupo 1 menos Grupo 2.
